## How to use

### Python 등 programming에 익숙하신 분들

- .py 파일 다운로드 하셔서 실행하시면 됩니다.

### Programming이 처음이신 분들

1. [Google Colab](https://colab.research.google.com/) 접속  # 구글 계정이 필요합니다.
2. 새 노트 생성
3. Empty Cell (`1. 코딩을시작하거나 AI로 코드를 생성하세요` 라고 적혀있어요)에, .py의 내용을 그대로 복사하여 붙여넣습니다. (copy and paste)
4. Cell옆의 동작버튼을 클릭합니다.
5. 하단의 실행결과 창에서 요구하는 입력을 넣습니다.
6. 결과를 확인합니다.
